# Valorant - Site em HTML

Site simples sobre o jogo **Valorant**, feito como trabalho de HTML. O projeto tem três páginas ligadas entre si por links (`<a>`), com informações sobre mapas, personagens e skins de armas.

## Páginas

| Página | Arquivo | Conteúdo |
| --- | --- | --- |
| Mapas | `mapas.html` | Lista de mapas na rotação, campo de busca e galeria com descrição de cada mapa |
| Personagens meta | `Personagensmeta.html` | Lista dos personagens mais fortes, galeria com descrições e tabela com posição, habilidade e função |
| Skins | `Skinsdevandal.html` | Lista das armas que mais valem a pena comprar skins, tipos de arma e tabela comparativa |

## Tags de HTML utilizadas

- **Estrutura semântica:** `header`, `nav`, `main`, `section`, `footer`, `figure`, `figcaption`
- **Texto e títulos:** `h1` a `h2`, `p`, `strong`, `div`
- **Links:** `a`
- **Listas:** `ol`, `ul`, `dl`, `dt`, `dd`
- **Imagens:** `img`
- **Formulário:** `label`, `input`, `button`
- **Tabela:** `table`, `caption`, `thead`, `tbody`, `tr`, `th`, `td`

> O CSS é opcional no trabalho. Foi usado apenas um estilo simples dentro de cada página para melhorar a visualização.

## Como executar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques em qualquer arquivo `.html` para abrir no navegador, ou use a extensão **Live Server** no VS Code.
4. Use o menu de navegação no topo para trocar de página.
